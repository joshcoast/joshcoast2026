# Theme Styles Source

These SCSS files are the source of truth for front-end styling.

- `style.scss` -> `assets/css/style.min.css` (shared/base styles)
- `theme-arcade.scss` -> `assets/css/theme-arcade.min.css` (Arcade mode)
- `theme-stripes.scss` -> `assets/css/theme-stripes.min.css` (Stripes mode)

Build commands:

- `npm run build` (production, minified)
- `npm run dev` (development build)
- `npm run watch` (rebuild on changes)
